# Блоки переноса

1. **Провайдеры и получение потока (приоритет)** — общий контракт, каталог/поиск/карточка/серии/озвучки, прямые URL и iframe fallback.
2. **Сеть** — cookies, Referer/Origin, таймауты, отмена, редиректы, HLS-плейлисты/сегменты и CDN.
3. **Плеер** — качество, переключение серий, прогресс, субтитры, фон/PiP, восстановление ошибок.
4. **Интерфейс** — навигация, каталог, фильтры, карточка, состояния загрузки.
5. **Данные** — избранное, история, прогресс и миграции.
6. **Настройки/медиа** — темы, звук; отдельная оценка переносимости mpv, шейдеров и Android-ускорения.
7. **Поставка и проверки** — IPA/CI, тесты парсеров, проверка на устройстве.

## Источники Android

Отдельные реализации: AniLiberty, AnimeGo, AnimeVost, YummyAnime, KinoKino;
группы webcatalog: WebCatalogProviders, AdditionalProviders, NewAnimeProviders,
FilmCatalogProviders, DoramaTvProvider. Mock не считать рабочим источником.
Каждая группа требует отдельной инвентаризации: файл не равен одному провайдеру.

## Текущее покрытие

- AniLiberty: первый каталог/поиск/серии; сеть и playback на устройстве не проверены.
- Веб-перехват: WKUserScript в каждом iframe, fetch/XHR, PerformanceObserver,
  HTML media src, дедупликация HLS/MP4, выбор обнаруженного URL. Ручной вход
  через «Веб-источник» позволяет проверить страницы до переноса их парсеров.
- Это наблюдение JavaScript, не полный сетевой перехват Android. Worker/service-worker,
  blob/MSE, DRM и URL без расширений этим механизмом не покрываются.
- Cookies/Referer/Origin обнаруженного потока в нативный плеер ещё не передаются;
  веб-плеер остаётся доступен на странице. Нельзя считать обнаружение URL гарантией воспроизведения.

## Очередь приоритета

1. Полный AniLiberty: resolve endpoint отдельной серии, качества, ошибки/повтор, pagination.
2. AnimeGo: HTML-парсер, пагинация серий, список озвучек, iframe → наблюдение потока.
3. Передача cookies и поддерживаемых заголовков, проверка HLS с вложенными плейлистами.
4. AnimeVost/YummyAnime и остальные группы, с fixture-тестами по каждому источнику.

Проверки фиксировать раздельно: компиляция, fixture, live endpoint, реальный iPhone.
